# Game controls 
w- up  
a- left  
d- right  

objective: complete the track by jumping over the obstacle and the platforms to reach to the golden platform where u try to win with the most apples collected.

# Running it locally
 download the Zip file and past it into a folder and open CMD panel from it's path.  
 - Run python -m http.server 8000. This needs Python installed.
 - Open http://localhost:8000 in your browser.
